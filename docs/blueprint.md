# **App Name**: Jayprakash's DevFolio

## Core Features:

- Hero & About Me Sections: Display professional name, title, brief introduction, call to action, and detailed bio with skill summaries.
- Skills & Experience Showcase: Present technical skills, possibly with progress indicators, and work experience in a timeline format.
- Project Portfolio: Showcase individual projects with titles, descriptions, tech stacks, and live/demo links, using dummy project data.
- Contact & Social Hub: Provide a contact form with client-side validation for messages and direct links to professional social profiles (LinkedIn, GitHub).
- Dynamic Theming & Responsiveness: Offer a dark/light mode toggle and ensure optimal viewing across all device types (mobile, tablet, desktop) with a fully responsive layout.
- Seamless User Experience: Implement smooth scrolling navigation, sticky header, hover effects, and subtle fade-in animations throughout the site.
- Resume Access: Enable easy access for visitors to download the developer's professional resume.

## Style Guidelines:

- Primary color: A vibrant, professional blue (#2962FF), symbolizing reliability and innovation, suitable for highlighting key elements and interactive components.
- Background color: A subtle, dark charcoal-blue (#111314) provides a sophisticated and modern foundation, appropriate for a dark theme and enhancing readability.
- Accent color: A bright, clear cyan (#6EE7FD) serves as a dynamic contrast, drawing attention to calls-to-action, active states, and informative details.
- Headlines and prominent text: 'Space Grotesk' (sans-serif), offering a modern, tech-inspired aesthetic.
- Body text and descriptive content: 'Inter' (sans-serif), chosen for its excellent legibility and neutral, objective feel.
- Code snippets and technical references: 'Source Code Pro' (monospace), ensuring code is clearly formatted and easily readable.
- Use a consistent set of professional-grade icons, such as Font Awesome, for skill representations, social links, and interactive elements to maintain a clean UI.
- Adopt a clean and modular layout, with clearly defined sections that are fully responsive across desktop, tablet, and mobile devices. Implement smooth scrolling for intuitive navigation and a sticky header for persistent access to menu options.
- Incorporate subtle, tasteful animations like fade-ins on scroll, hover effects on interactive elements (e.g., project cards, buttons), and smooth transitions for the dark/light theme toggle, enhancing user engagement without being distracting.
