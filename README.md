# Jayprakash Gurjar — Portfolio

A personal portfolio site built with React, TypeScript, Vite, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:9002`.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — production build (output in `dist/`)
- `npm run preview` — preview the production build locally
- `npm run typecheck` — run the TypeScript compiler without emitting files

## Contact form

The contact form writes submissions to Firebase Firestore. Copy `.env.example` to `.env` and fill in your Firebase project's config (`VITE_FIREBASE_*`) to enable it.
